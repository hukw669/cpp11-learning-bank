# 有效指令记录

本文件保存经过整理、仍然有效的项目要求，不保存原始聊天记录。

## 需求演变

1. 早期 C 语言题库方案停止，主线改为 C++11 零基础题库。
2. 不再假定学习者已经掌握 C 或旧版 C++。
3. 出题由少量测试改为每批 30 题，并要求范围最终全覆盖。
4. 答题形式改为每道题下面直接附答案。
5. 增加知识节点标记和同节点连续排列要求。
6. 用户主动提出的技术问题统一写入错题本。
7. 学习材料改为 Markdown，不生成 Word。
8. 本次明确授权将学习仓库提交并发布到 GitHub；这不自动代表以后每次修改都可永久自动推送。
9. 本次 GitHub 仓库明确创建为公有仓库。

## 题目生成指令

```text
按 docs/题库生成与维护规则.md 生成下一批 30 道题。
编号承接上一批；每题下方直接给答案；同节点连续排列；
严格 C++11；不假定未讲知识；完成选定范围的实质覆盖；
生成后检查题号、答案、节点、代码围栏和标准版本。
```

## 错题本指令

```text
把用户本轮技术疑问加入 wrongbook/wrongbook.md。
先搜索是否已有同一知识点；有则补充，无则使用下一个连续 W 编号。
答案从零解释，给出最小 C++11 示例、易错点和一句话记忆。
```

## 发布前指令

```text
只在 cpp11-learning-bank 独立仓库内操作。
检查待提交文件、题号连续性、答案数量、代码围栏和隐私信息。
不得提交桌面其他目录、原始聊天、本机绝对路径、令牌或个人资料。
```

## 不保存的内容

- 原始聊天、系统提示和权限信息。
- Windows 用户名、本机绝对路径和临时附件路径。
- 访问令牌、登录信息、邮箱和私钥。
- 与 C++11 学习无关的个人教育、求职或项目资料。
- 其他代码仓库和工作目录中的文件。
- 受版权保护的书籍正文或未经授权的电子书。
