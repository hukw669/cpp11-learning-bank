# C++11 STL 细节与易混操作专题设计

## 目标

在 `cpp11-learning-bank` 中新增一份可独立阅读的 C++11 细节专题，把本轮对话中零散出现的 STL、迭代器、值类别和运算符知识整理成一条可复习、可对比、可运行验证的学习路径。文档重点不是枚举接口，而是回答“两个相似写法究竟哪里不同”。

## 方案比较

### 方案 A：新增一份独立细节专题（采用）

创建 `sections/08_C++11细节知识点与STL易混操作.md`，在一个文件内用稳定章节和对照表组织内容，并在 README、总索引增加入口。

优点：符合用户“新开一个细节知识点 md”的要求；可以集中对比相似 API；不继续膨胀已有 `02_类模板STL.md`。缺点：与既有主图节点会有少量知识交叉，需要明确这是复习深化页而不是新增覆盖节点。

### 方案 B：追加到 `02_类模板STL.md`

优点：所有 STL 内容集中。缺点：原文件已经承担完整主线，继续追加会降低定位效率，也不满足新建独立 Markdown 的直接要求。

### 方案 C：拆成多个小专题

分别创建迭代器、容器操作、算法、转发等文件。优点：边界清晰。缺点：本轮内容关联紧密，拆分会造成跳转过多和重复解释，当前没有必要。

## 文档结构

新专题按以下顺序组织：

1. 阅读地图与 C++11 版本边界。
2. `{}`、临时结果和 `return {}`。
3. `array`、`pair`、`tuple`、`struct` 的类型与初始化差异。
4. `map` 元素类型、迭代器、`first/second` 与 key 不可修改。
5. STL 操作的初始化、增加、删除、修改、查询总表。
6. 同类 API 对照：`operator[]/at/find`、`insert/emplace`、`push_back/emplace_back`、成员查找/通用算法、`erase/remove`、`unique/整体去重`、算法/成员 `lower_bound`。
7. 迭代器模型、类别、常用操作与循环模板。
8. 插入、删除、扩容、rehash 的迭代器失效规则。
9. 常用算法详解：`find/count/sort/copy/remove/unique/reverse/lower_bound/upper_bound/distance/advance`。
10. 位运算、逻辑运算和文字替代运算符。
11. `std::move`、转发引用、引用折叠与 `std::forward`。
12. 记忆方法、选择流程和综合检查表。

## 内容规则

- 主线只使用 ISO C++11；结构化绑定、`contains`、`try_emplace`、`insert_or_assign` 等必须标注后续版本。
- 每组易混操作至少给出：核心差异、是否修改容器、失败方式、返回值、复杂度、迭代器影响、最小示例和选择口诀。
- `{...}` 的含义必须按上下文解释，区分初始化对象、初始化内部数组、一个 `pair` 和多个元素。
- 标准保证与常见实现分开。例如 `map` 保证有序和对数复杂度，但标准不要求实现一定是红黑树。
- 代码块必须能独立理解；故意错误的片段明确标注“错误示例”，避免被误当作可运行代码。
- 新专题是对既有 C++ 节点的深化索引，不增加或虚报 533/690 覆盖数字。
