# C++ 八股知识库：操作系统与计算机网络分科设计

## 1. 背景与目标

现有仓库以 C++11、STL、并发和工程知识为主，已经形成知识图谱、690 道题、统一错题本、维护规则、校验工具和异步 agent 工作流。后续学习范围扩展到操作系统与计算机网络，但仓库名和 GitHub 地址继续保持 `cpp11-learning-bank`，避免破坏已有链接与提交历史。

本次改造目标是：

1. 把仓库的内容定位扩展为“C++ 八股知识库”。
2. 新增操作系统与计算机网络两份独立知识点 Markdown。
3. 将 C++、操作系统、计算机网络错题分开维护。
4. 保持主 agent 快速回答、后台 agent 异步落盘的现有体验。
5. 保留现有 690 道题、C++ 知识节点、历史错题编号和 GitHub 仓库地址。

## 2. 非目标

本次不执行以下工作：

- 不重命名 GitHub 仓库或修改远端地址。
- 不重排现有 C++ 错题的历史编号。
- 不重写现有 690 道题，也不立即批量生成 OS/计网题库。
- 不把操作系统或网络平台行为冒充 ISO C++11 规则。
- 不复制知乎文章全文；仅保留原创总结、纠错和来源链接。

## 4. 三本错题本的职责与编号

| `wrongbook/os_wrongbook.md` | 进程线程、调度、同步、死锁、内存、文件系统、I/O、系统调用等 | `OSW001`、`OSW002`…… |
| `wrongbook/network_wrongbook.md` | 网络分层、应用协议、传输层、IP、链路层、Socket 和网络工程等 | `NETW001`、`NETW002`…… |

每本错题本独立包含：

- 正文条目；
- 返回目录链接；
- 自己的历史最大编号时间线。

删除条目时不重排、不复用编号。新编号使用对应错题本历史中从未使用过的最大编号加一。

## 5. 技术问题路由规则

主 agent 先回答，再根据主要考点异步路由：

```text
C++/STL/编译链接/动态库/并发库 → wrongbook.md
操作系统机制                        → os_wrongbook.md
计算机网络协议与网络编程            → network_wrongbook.md
```

跨主题问题只保存一份完整正文：

1. 根据用户真正困惑的核心选择主错题本。
2. 其他主题若需要导航，只保存相对链接和一句关联说明。
3. 不在多本错题本复制同一篇正文。

例如：

- “TCP `TIME_WAIT` 的原因”进入计网错题本。
- “Linux 进程的虚拟内存”进入 OS 错题本。
- “C++ Socket RAII 封装怎样设计”若核心是资源所有权，进入 C++ 错题本并链接 Socket 知识节点；若核心是 TCP 语义，则进入计网错题本。

同一目标错题本同一时刻只能有一个 writer；不同错题本也不得同时暂存或提交，以免争用共享 Git 索引。

## 9. 标准、版本和来源边界

- C++ 内容继续严格标注 ISO C++11 与后续标准差异。
- 操作系统内容区分教材抽象、POSIX、Linux 实现和硬件相关事实。
- 网络内容优先引用 RFC Editor、IETF、IEEE 等原始规范。
- 二手文章只作为扩展学习来源；与现行标准冲突时，以规范和明确版本为准。
- 历史内容必须标记，例如分类地址、RARP、SSL 和旧 HTTP 行为。

`SOURCES.md` 增加 OS 与计网来源分区，至少记录用户给出的知乎文章和相关 RFC。
