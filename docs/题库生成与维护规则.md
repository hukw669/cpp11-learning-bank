# 题库生成与维护规则

本文件是后续生成 C++11 题目时的执行规范。

## 1. 标准范围

1. 主线必须符合 ISO C++11。
2. 不假定学习者学过 C、C++98/03 或任何未选中的知识节点。
3. C 语言内容只在解释 C++ 兼容接口或版本差异时补充。
4. CMake、动态库、ELF、Linux/POSIX 等必须标为工程知识。
5. C++14 以后内容只能用于版本辨析，并明确说明 C++11 不可用。
6. 不得把编译器扩展、常见平台行为或实现习惯写成标准保证。

常见的非 C++11 特性包括但不限于：

- C++14：泛型 Lambda、`std::make_unique`、变量模板。
- C++17：结构化绑定、`if constexpr`、`std::optional`、`std::variant`、`std::string_view`、`std::byte`、内联变量。
- C++20：概念、范围库、协程、指定成员初始化、三路比较。

## 2. 批次规则

1. 每批恰好 30 题。
2. 编号从上一题加一开始，连续、唯一且不缺号。
3. 文件名为 `batch_NN_SSS_EEE.md`，其中 `SSS`、`EEE` 是三位题号。
4. 每题下方立即给出答案和必要解释。
5. 同一知识节点的题目必须连续排列。
6. 每题标注主知识节点；确有必要时再标注关联节点。
7. 题型以概念、判断、代码阅读、推理和最小纠错为主。
8. 不强制每个节点固定题数；复杂节点可以多题覆盖。

推荐的统一格式：

```markdown
# C++11 第 N 批题目（SSS–EEE）

## 061.【B4.1 声明与定义】【概念】问题正文

**答案：** 先直接回答，再解释原因。
```

## 3. 答案规则

1. 每题只能有一个紧随题目的 `**答案：**`。
2. 先给结论，再解释规则和原因。
3. 不用尚未讲解的术语替代解释；必须使用时，先给定义。
4. 示例代码必须符合 C++11，故意错误的代码要明确标注预期错误。
5. 必须准确区分：
   - 非良构或编译错误；
   - 链接错误；
   - 装载错误；
   - 未定义行为；
   - 未指定行为；
   - 实现定义行为；
   - 逻辑错误。
6. 无法从标准唯一确定输出时，不编造唯一答案。
7. “常见为 8 字节”“通常输出某值”等实现事实必须写出前提。

## 4. 全覆盖规则

1. 以知识图谱叶子节点作为最小覆盖单位。
2. 每个选中节点至少有一道直接考查题。
3. 复杂节点应覆盖定义、使用条件、边界和常见错误。
4. 不能仅在题目标签中出现节点名就宣称完成覆盖。
5. 每批生成前先检查未覆盖节点，优先补齐缺口。
6. 当前基础核心基线为 99/99 个叶子节点，题目范围为 001–240。

## 5. 生成流程

### 第一步：确定范围

从总图中选择节点，例如：

```text
下一批范围：B4.1–B5.5
```

若没有指定范围，则优先选择尚未覆盖或需要强化的节点。

### 第二步：分配题量

- 每个节点至少一道直接题。
- 容易混淆的节点增加对比、反例或纠错题。
- 同一节点的题保持相邻。
- 题量总计必须为 30。

### 第三步：编写题目与答案

- 不把答案藏到独立文件。
- 代码示例必须具有足够上下文。
- 问题必须说明需要回答什么。
- 答案必须解释“为什么”，不能只给选项字母。

### 第四步：更新覆盖关系

记录每个节点对应的题号，并确认没有遗漏选中节点。

### 第五步：处理主动提问

若用户继续追问，将问题写入错题本；若属于已有条目，更新同一条目。

### 第六步：发布前验证

完成本文件末尾的检查清单，再提交到版本库。

## 6. 标准生成提示词

```text
你是 ISO C++11 零基础题库生成器。

按知识图谱为指定范围生成下一批 30 道题，编号承接上一批。
不假定学习者学过 C、旧版 C++ 或未选择的节点。
每题标注知识节点；同一节点的题连续排列。
每题下面立即给出答案，答案先给结论，再解释原因。
题型可使用概念、判断、代码阅读、推理和最小纠错。
必须区分编译错误、链接错误、未定义行为、未指定行为和实现定义行为。
严格使用 C++11；不得把 C++14/17/20 或编译器扩展写成 C++11。
输出 UTF-8 Markdown，不生成 Word。
生成后验证：30 题、30 个答案、编号连续、节点无遗漏、代码围栏配对。
```

- [ ] 每题存在知识节点标签。
- [ ] 每个答案位于本题和下一题之间。
- [ ] 同一节点在单个批次中连续排列。
- [ ] 选定知识节点全部得到实质覆盖。
- [ ] Markdown 代码围栏成对。
- [ ] 没有把后续标准特性误称为 C++11。
