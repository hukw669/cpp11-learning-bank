## 学习顺序

1. 从[总图与选题索引](./00_总图与选题索引.md)选择节点。
2. 在 `sections/` 阅读对应知识点。
3. 每次学习 `questions/` 中一个 30 题批次；每题下方已经紧跟答案。
4. 对任何不理解的答案继续追问。
5. 技术追问、答错题和边界误解写入[错题本](./wrongbook/wrongbook.md)。
6. 回看错题时先遮住“核心答案”，独立复述，再对照最小示例和易错点。

## 标准边界

- 主线严格按照 ISO C++11。
- 不把 C 规则当作 C++11 规则。
- 不假定学过 C、C++98/03 或尚未选择的节点。
- C++14/17/20 内容只能用于版本辨析，并必须明确标注“不属于 C++11”。
- CMake、ELF、动态库、Linux/POSIX 等属于工程扩展知识，不冒充 ISO C++11 语言规则。

## 如何继续生成

完整规则见[题库生成与维护规则](./docs/题库生成与维护规则.md)。标准指令为：

```text
按题库生成与维护规则生成下一批 30 道题。编号承接上一批；
从指定节点或尚未覆盖节点选题；每题下面直接给答案；
同一节点连续排列；不假定未讲知识；严格限制在 C++11；
生成后检查题号、答案、节点覆盖、代码围栏和版本边界。
```

## 如何维护错题本

规则见[错题本维护规则](./docs/错题本维护规则.md)。用户主动提出技术疑问、答错、表示不知道或继续追问时，应自动记录；相同知识点优先补充原条目，不机械制造重复条目。
