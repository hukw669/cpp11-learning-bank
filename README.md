# C++ 八股知识库

本仓库面向没有 C 或旧版 C++ 前置知识的学习者，以 ISO C++11 为 C++ 主线，并收录操作系统与计算机网络面试知识图谱，将知识图谱、分批题目、答案和主动提问错题本放在同一个可持续维护的学习系统中。仓库目录名与远端仓库名仍为 `cpp11-learning-bank`，不因展示名称调整而变更。

## 学习顺序

1. 从[总图与选题索引](./00_总图与选题索引.md)选择节点。
2. 在 `sections/` 阅读对应知识点。
3. 每次学习 `questions/` 中一个 30 题批次；每题下方已经紧跟答案。
4. 对任何不理解的答案继续追问。
5. 技术追问、答错题和边界误解按学科写入错题本：[C++](./wrongbook/wrongbook.md)、[操作系统](./wrongbook/os_wrongbook.md)、[计算机网络](./wrongbook/network_wrongbook.md)。
6. 回看错题时先遮住“核心答案”，独立复述，再对照最小示例和易错点。

操作系统学习从 [06_操作系统八股.md](./sections/06_操作系统八股.md) 的 OS1 开始；计算机网络学习从 [07_计算机网络八股.md](./sections/07_计算机网络八股.md) 的 NET1 开始。两者暂只提供知识图谱与错题本，尚未生成独立题目批次。

C++ 容器、迭代器、算法、花括号初始化、位运算以及 `move/forward` 的易混细节，可集中阅读 [08_C++11细节知识点与STL易混操作.md](./sections/08_C++11细节知识点与STL易混操作.md)。该专题映射既有 C++ 节点，是复习深化入口，不增加或改变当前 533/533 节点与 690 题的覆盖口径。

## 标准边界

- 主线严格按照 ISO C++11。
- 不把 C 规则当作 C++11 规则。
- 不假定学过 C、C++98/03 或尚未选择的节点。
- C++14/17/20 内容只能用于版本辨析，并必须明确标注“不属于 C++11”。
- CMake、ELF、动态库、Linux/POSIX 等属于工程扩展知识，不冒充 ISO C++11 语言规则。

## 如何继续生成

完整规则见[题库生成与维护规则](./docs/题库生成与维护规则.md)。下列标准指令目前用于 C++ 题库：

```text
按题库生成与维护规则生成下一批 30 道题。编号承接上一批；
从指定节点或尚未覆盖节点选题；每题下面直接给答案；
同一节点连续排列；不假定未讲知识；严格限制在 C++11；
生成后检查题号、答案、节点覆盖、代码围栏和版本边界。
```
