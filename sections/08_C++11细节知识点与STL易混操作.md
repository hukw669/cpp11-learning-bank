# C++11 细节知识点与 STL 易混操作

> 定位：这是一份复习深化页，不新增题库覆盖节点。它把既有 `B6/B11/B13/R4/T6/S1–S12/ITER1/ALG1–ALG8` 中容易混淆的细节按“相似操作对照”重新组织。

## D1 阅读地图与版本边界

学习 STL 时不要孤立背函数名，先判断三件事：

1. 当前对象属于哪一类容器；
2. 操作是在改变容器结构，还是处理一个迭代器范围；
3. 操作完成后，元素、引用和迭代器是否仍然有效。

本页严格以 ISO C++11 为主线。下列常见写法不属于 C++11：

| 写法 | 首次版本 | C++11 替代方式 |
|---|---:|---|
| `for (auto& [key, value] : mp)` | C++17 | 遍历 `pair`，使用 `first/second` |
| `map::try_emplace` | C++17 | `emplace` 或先 `find` |
| `map::insert_or_assign` | C++17 | `find` 后赋值，或使用 `operator[]` |
| `map::contains` | C++20 | `find` 或 `count` |
| `std::make_unique` | C++14 | C++11 中直接构造 `unique_ptr` |

标准库名字不是语言关键字：`vector`、`map`、`pair`、`tuple`、`move`、`forward` 都是 `std` 命名空间中的类型或函数。

## D2 花括号初始化、临时对象与 `return {}`

### 1. `{}` 本身没有固定类型

花括号列表的含义由上下文决定：

```cpp
std::vector<int> v{1, 2, 3};           // 初始化三个 int
std::pair<int, int> p{1, 2};           // 初始化一个 pair
std::map<int, int> mp{{1, 10}, {2, 20}}; // 初始化两个键值对
```

因此不能只看到 `{1, 2}` 就断定它是数组、列表或 `pair`。必须先看目标类型或函数重载。

### 2. `return {}`

`return {}` 使用函数已经声明的返回类型进行列表初始化：

```cpp
int zero() {
    return {};                 // 返回 0
}

std::vector<int> empty_vector() {
    return {};                 // 返回空 vector
}

std::map<int, int> empty_map() {
    return {};                 // 返回空 map
}

std::pair<int, int> point() {
    return {10, 20};           // 返回一个 pair
}
```

`{}` 不是一个可以独立推导的普通表达式，因此下面不能仅凭空花括号推导 `auto` 返回类型：

```cpp
// auto bad() {
//     return {};              // 错误：没有返回类型上下文
// }
```

`return {}` 仍会构造返回对象；它不表示“什么都不构造”。

### 3. `std::array` 的双层花括号

```cpp
std::array<int, 3> a{{1, 2, 3}};
```

可以把外层理解为初始化 `std::array` 聚合对象，内层理解为初始化其封装的固定长度数组。允许花括号省略的实现中也常见：

```cpp
std::array<int, 3> a{1, 2, 3};
```

双层写法明确表达了两层聚合关系，也兼容一些较旧的 C++11 编译器习惯。

### 4. `insert(pos, {...})` 是一个还是多个元素

对顺序容器，初始化列表重载插入多个元素：

```cpp
std::vector<int> v{1, 4};
v.insert(v.begin() + 1, {2, 3}); // v 为 1,2,3,4
```

对 `map`，一层 `{key, value}` 通常构造一个 `pair`：

```cpp
std::map<int, std::string> mp;
mp.insert({1, "Tom"});           // 一个键值对
mp.insert({{2, "Jerry"}, {3, "Alice"}}); // 多个键值对
```

记忆：先看函数期待的是一个 `value_type`，还是 `initializer_list<value_type>`。

## D3 `array`、`pair`、`tuple` 与 `struct`

| 类型 | 元素数量 | 元素类型 | 访问方式 | 适用语义 |
|---|---:|---|---|---|
| `array<T,N>` | 编译期固定 | 全部相同 | `a[i]`、`at` | 一批同类元素 |
| `pair<T1,T2>` | 固定为 2 | 可以不同 | `first/second` | 两个有固定角色的值 |
| `tuple<T...>` | 0 个或多个 | 可以不同 | `get<N>` | 临时组合多个异类值 |
| `struct` | 自定义 | 可以不同 | 有意义的字段名 | 稳定的业务数据结构 |

### `pair`

```cpp
#include <utility>

std::pair<int, std::string> user{1, "Tom"};
int id = user.first;
std::string name = user.second;
```

`pair` 只有 `first` 和 `second`，没有 `third`。

### `tuple`

`std::tuple` 从 C++11 开始支持，元素数量不限于三个：

```cpp
#include <tuple>

std::tuple<int, std::string, double> student{1, "Tom", 95.5};
int id = std::get<0>(student);
std::string name = std::get<1>(student);
double score = std::get<2>(student);
```

`std::get<N>` 中的 `N` 必须是编译期常量：

```cpp
// int i = 1;
// std::get<i>(student); // 错误
```

结构化绑定是 C++17，不属于 C++11。

### 什么时候选择 `struct`

如果每个字段有稳定业务含义，结构体比 `tuple` 更清楚：

```cpp
struct Student {
    int id;
    std::string name;
    double score;
};
```

口诀：同类数据用 `array`；两个临时角色用 `pair`；多个临时异类值用 `tuple`；长期业务模型用 `struct`。

## D4 `map` 元素、迭代器与 `first/second`

### 1. `map` 的元素类型

```cpp
std::map<Key, T>::value_type
```

本质上是：

```cpp
std::pair<const Key, T>
```

例如：

```cpp
std::map<int, std::string> mp{{1, "Tom"}};
std::map<int, std::string>::iterator it = mp.begin();
```

```cpp
it->first;   // key，类型近似 const int
it->second;  // value，类型为 string
```

### 2. `it->member` 的含义

迭代器不是必须等于原生指针，但它提供类似指针的访问接口：

```cpp
it->second
```

等价于：

```cpp
(*it).second
```

拆解：

```text
it            map 迭代器
*it           当前 pair<const Key,T> 元素
(*it).second  pair 的 value 字段
```

### 3. key 为什么不能修改

```cpp
// it->first = 2;       // 错误
it->second = "Jerry";   // 正确
```

`map` 的排序结构依赖 key。直接修改 key 会破坏容器不变量，因此标准把 key 暴露为 `const Key`。

### 4. C++11 遍历

```cpp
for (std::map<int, std::string>::iterator it = mp.begin();
     it != mp.end(); ++it) {
    std::cout << it->first << ' ' << it->second << '\n';
}
```

也可以使用 `auto`：

```cpp
for (auto it = mp.begin(); it != mp.end(); ++it) {
    std::cout << it->first << ' ' << it->second << '\n';
}
```

## D5 STL 初始化与增删改查总表

### 1. 容器家族

| 家族 | 容器 | 核心特征 |
|---|---|---|
| 固定序列 | `array` | 固定长度、连续存储、不能增删 |
| 动态序列 | `vector` | 连续存储、尾部高效、会扩容 |
| 双端序列 | `deque` | 头尾插入高效、非单块连续存储 |
| 链式序列 | `list/forward_list` | 节点存储、稳定迭代器 |
| 有序关联 | `set/map/multiset/multimap` | 按比较器排序 |
| 无序关联 | `unordered_*` | 哈希组织、可能 rehash |
| 容器适配器 | `stack/queue/priority_queue` | 限制访问接口、没有迭代器 |

### 2. 通用操作矩阵

| 分类 | 顺序容器 | `map/set` | `unordered_*` | 适配器 |
|---|---|---|---|---|
| 初始化 | `{}`、范围构造、数量构造 | `{}`、范围构造 | `{}`、范围构造 | 默认或指定底层容器 |
| 增加 | `push_*`、`insert`、`emplace` | `insert`、`emplace` | `insert`、`emplace` | `push`、`emplace` |
| 删除 | `pop_*`、`erase`、`clear` | `erase(key/it/range)` | `erase(key/it/range)` | `pop` |
| 修改 | `[]`、`at`、迭代器解引用 | `map` 修改 `second` | `unordered_map` 修改 `second` | 只能访问受限端点 |
| 查询 | `[]`、`at`、`front/back` | `find/count/lower_bound` | `find/count` | `top` 或 `front/back` |
| 容量 | `size/empty`，部分有 `capacity` | `size/empty` | 另有桶和负载因子 | `size/empty` |

### 3. 常见初始化变式

```cpp
std::vector<int> a;                 // 空
std::vector<int> b(5);              // 5 个值初始化元素
std::vector<int> c(5, 10);          // 5 个 10
std::vector<int> d{1, 2, 3};        // 初始化列表
std::vector<int> e(d.begin(), d.end()); // 范围构造
```

### 4. 常见插入变式

```cpp
v.push_back(value);
v.emplace_back(args...);
v.insert(pos, value);
v.insert(pos, count, value);
v.insert(pos, first, last);
v.insert(pos, {1, 2, 3});
v.emplace(pos, args...);
```

### 5. 常见删除变式

```cpp
v.pop_back();
v.erase(pos);
v.erase(first, last);
v.clear();
```

关联容器还可以按 key 删除：

```cpp
std::size_t removed = mp.erase(key);
```

`map/set` 返回 `0` 或 `1`；多重关联容器可能返回大于 `1`。

### 6. 特殊容器边界

- `array`：无 `insert/erase/push/pop/resize`。
- `forward_list`：使用 `insert_after/erase_after`，没有随机下标和 `back`。
- `stack/queue/priority_queue`：没有公开迭代器，按适配器接口访问。
- `multimap`：没有 `operator[]` 和 `at`，因为一个 key 可能对应多个 value。

## D6 相似容器接口的行为差异

### 1. `mp[key]`、`mp.at(key)`、`find`、`count`

| 操作 | key 不存在 | 是否插入 | 返回/失败方式 | 典型用途 |
|---|---|---:|---|---|
| `mp[key]` | 构造默认 value | 是 | 返回 value 引用 | 插入或更新、计数 |
| `mp.at(key)` | 不插入 | 否 | 抛 `out_of_range` | 确认 key 应存在时访问 |
| `mp.find(key)` | 不插入 | 否 | 返回 `end()` | 查找并继续使用迭代器 |
| `mp.count(key)` | 不插入 | 否 | `map` 返回 0/1 | 只判断是否存在 |

```cpp
std::map<int, int> mp;
int value = mp[7];       // 插入 {7,0}

auto it = mp.find(8);    // 不插入
if (it == mp.end()) {
    // 8 不存在
}
```

不要使用 `mp[key]` 做纯存在性判断，因为它会修改容器。

### 2. `insert`、`emplace`、`operator[]`

| 操作 | 已存在 key | 构造行为 | 返回值 |
|---|---|---|---|
| `insert(value)` | 不覆盖 | 先有完整 `value_type` | `pair<iterator,bool>` |
| `emplace(args...)` | 不覆盖 | 从参数构造元素 | `pair<iterator,bool>` |
| `operator[]` | 返回旧 value 引用，可随后覆盖 | 不存在时默认构造 value | `mapped_type&` |

```cpp
mp.insert(std::make_pair(1, 10));
mp.emplace(2, 20);
mp[1] = 99;
```

`try_emplace` 和 `insert_or_assign` 是 C++17，不应写入 C++11 主线代码。

### 3. `push_back` 与 `emplace_back`

```cpp
v.push_back(T(args...));
v.emplace_back(args...);
```

`push_back` 接收已经存在或临时构造的 `T`；`emplace_back` 把构造参数传给元素构造函数。`emplace_back` 不是自动更快：简单类型、已有对象或编译器消除临时对象时，差异可能很小。

### 4. 成员 `find` 与 `std::find`

```cpp
mp.find(key);                         // 利用 map 结构，O(log n)
std::find(v.begin(), v.end(), value); // 通用线性查找，O(n)
```

口诀：容器管理自己的结构，算法处理一个迭代器范围。关联容器查 key 优先成员函数。

### 5. `erase` 与 `remove`

`erase` 是容器成员函数，真正改变容器大小：

```cpp
v.erase(pos);
```

`std::remove` 是算法，把保留元素向前移动，返回新的逻辑末尾，不改变容器大小：

```cpp
v.erase(std::remove(v.begin(), v.end(), value), v.end());
```

### 6. `unique` 与整体去重

`std::unique` 只压缩相邻重复元素，并且不改变容器大小：

```cpp
std::sort(v.begin(), v.end());
v.erase(std::unique(v.begin(), v.end()), v.end());
```

这会整体去重，但排序改变原顺序。若要保留首次出现顺序，可以用 `unordered_set` 记录已见元素并写入结果容器。

### 7. 算法与成员 `lower_bound`

```cpp
std::lower_bound(v.begin(), v.end(), x); // 要求范围已排序
mp.lower_bound(key);                     // 使用 map 自身比较器与树结构
```

对 `map/set` 优先成员版本。对有序 `vector` 使用算法版本。

## D7 迭代器模型、类别与循环模板

### 1. 迭代器不是必然等于指针

迭代器是满足特定访问协议的类型。`vector` 迭代器通常接近指针；`map` 迭代器通常封装树节点位置。共同操作包括：

```cpp
*it;       // 当前元素
it->member;
++it;      // 下一个位置
it != end;
```

### 2. 主要迭代器类别

| 类别 | 额外能力 | 常见容器 |
|---|---|---|
| 输入 | 单向读取 | 输入流迭代器 |
| 输出 | 单向写入 | 插入迭代器 |
| 前向 | 可多次遍历、只向前 | `forward_list`、`unordered_*` |
| 双向 | 支持 `++/--` | `list`、`map/set` |
| 随机访问 | 支持 `+/-/[]/<` | `vector/array/deque` |

因此：

```cpp
v.begin() + 3;  // 正确
// mp.begin() + 3; // 错误
```

### 3. 边界函数

```cpp
c.begin();   c.end();
c.cbegin();  c.cend();
c.rbegin();  c.rend();
```

`end()` 是尾后位置，不能解引用。

### 4. 只读、修改与 map 遍历

```cpp
for (const auto& value : v) {
    std::cout << value << '\n';
}

for (auto& value : v) {
    ++value;
}

for (const auto& entry : mp) {
    std::cout << entry.first << ' ' << entry.second << '\n';
}
```

### 5. 循环删除模板

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (should_remove(*it)) {
        it = v.erase(it);
    } else {
        ++it;
    }
}
```

删除分支不能再额外执行 `++it`，因为 `erase` 已返回下一个有效位置。

## D8 插入删除、扩容与迭代器失效

| 容器 | 插入影响 | 删除影响 |
|---|---|---|
| `vector` | 扩容时全部失效；未扩容时插入点及其后通常失效 | 删除点及其后失效 |
| `deque` | 中间插入通常使大量迭代器失效 | 中间删除通常使大量迭代器失效 |
| `list/forward_list` | 其他元素迭代器通常保持有效 | 仅被删除元素失效 |
| `map/set` | 已有迭代器通常保持有效 | 仅被删除元素失效 |
| `unordered_*` | 触发 rehash 时所有迭代器失效 | 通常仅被删除元素失效 |

### `vector` 扩容

```cpp
std::vector<int> v;
v.reserve(100);
```

`reserve` 可以降低增长过程中的重新分配次数，但中间位置插入仍可能使插入点及后方迭代器失效。

危险模式：

```cpp
auto it = v.begin();
v.push_back(10); // 可能扩容
// 使用 it 可能产生未定义行为
```

### `unordered_map` rehash

```cpp
std::unordered_map<int, int> mp;
mp.reserve(1000);
```

插入导致桶数量变化时会 rehash，旧迭代器失效。不要在保存迭代器后继续插入再使用旧迭代器；可以复制需要的数据，或插入后重新 `find`。

这些问题在在线判题中也会出现。未定义行为可能崩溃、答案错误，也可能暂时通过；不能依赖“测试没崩”。

## D9 常用算法与迭代器工具详解

### 总表

| 函数 | 作用 | 返回值 | 前提/复杂度重点 |
|---|---|---|---|
| `find` | 找第一个等于目标值 | 迭代器或 `last` | 线性 `O(n)` |
| `count` | 统计目标值 | 数量 | 线性 `O(n)` |
| `sort` | 排序范围 | `void` | 随机访问，`O(n log n)` |
| `copy` | 复制范围 | 输出末尾 | 输出空间必须足够 |
| `remove` | 压缩保留元素 | 新逻辑末尾 | 不缩小容器 |
| `unique` | 压缩相邻重复 | 新逻辑末尾 | 仅处理相邻重复 |
| `reverse` | 反转范围 | `void` | 至少双向迭代器 |
| `lower_bound` | 第一个 `>= x` | 迭代器 | 范围必须按同规则排序 |
| `upper_bound` | 第一个 `> x` | 迭代器 | 范围必须按同规则排序 |
| `distance` | 计算迭代器距离 | `difference_type` | 随机访问 O(1)，否则常为 O(n) |
| `advance` | 原地移动迭代器 | `void` | 能力取决于迭代器类别 |
| `next/prev` | 返回移动后的副本 | 迭代器 | 不修改原迭代器 |
| `iter_swap` | 交换两个位置的元素 | `void` | 元素必须可交换 |

### 查找与统计

```cpp
auto it = std::find(v.begin(), v.end(), value);
if (it != v.end()) {
    std::cout << *it;
}

auto n = std::count(v.begin(), v.end(), value);
```

### 排序与比较器

```cpp
std::sort(v.begin(), v.end());
std::sort(v.begin(), v.end(), std::greater<int>());
```

自定义比较器必须形成严格弱序；例如升序比较应使用 `<`，不能使用 `<=`。

### 安全复制

```cpp
std::vector<int> out;
std::copy(v.begin(), v.end(), std::back_inserter(out));
```

若直接写 `out.begin()`，必须预先确保目标范围存在足够元素。

### 删除和去重

```cpp
v.erase(std::remove(v.begin(), v.end(), value), v.end());

std::sort(v.begin(), v.end());
v.erase(std::unique(v.begin(), v.end()), v.end());
```

### 反转和二分边界

```cpp
std::reverse(v.begin(), v.end());

auto first = std::lower_bound(v.begin(), v.end(), value);
auto last = std::upper_bound(v.begin(), v.end(), value);
auto occurrences = last - first; // vector 随机访问迭代器
```

`lower_bound/upper_bound` 使用前，范围必须按相同比较规则保持有序。

### 距离和移动

```cpp
auto it = v.begin();
std::advance(it, 3);          // 修改 it
auto it2 = std::next(it, 2);  // it 不变
auto it3 = std::prev(it2, 1);
auto n = std::distance(v.begin(), it3);
std::iter_swap(v.begin(), it3);
```

`advance` 使用负数要求双向或随机访问迭代器。

## D10 位运算、逻辑运算与文字替代符

### 1. 位运算

| 运算符 | 作用 | 常用场景 |
|---|---|---|
| `&` | 按位与 | 测试位、保留掩码 |
| `|` | 按位或 | 设置位 |
| `^` | 按位异或 | 翻转位 |
| `~` | 按位取反 | 生成反掩码 |
| `<<` | 左移 | 构造位掩码 |
| `>>` | 右移 | 提取高位或缩小无符号值 |

```cpp
unsigned mask = 1u << k;
bits |= mask;      // 设置第 k 位
bits &= ~mask;     // 清除第 k 位
bits ^= mask;      // 翻转第 k 位
bool set = (bits & mask) != 0;
```

`1u` 是类型为 `unsigned int`、值为 1 的整数字面量。位运算优先使用无符号类型；移位数量不能为负或达到/超过类型位宽。

### 2. 逻辑运算

| 运算符 | 作用 | 是否短路 |
|---|---|---:|
| `&&` | 逻辑与 | 是 |
| `||` | 逻辑或 | 是 |
| `!` | 逻辑非 | 不适用 |

```cpp
if (ptr != nullptr && ptr->ready()) {
    // ptr 为空时不会求值右侧
}
```

`&` 和 `|` 处理各个二进制位；`&&` 和 `||` 把操作数转换为真假，并产生布尔结果。

### 3. 文字替代符

| 符号 | 文字写法 |
|---|---|
| `&` | `bitand` |
| `|` | `bitor` |
| `^` | `xor` |
| `~` | `compl` |
| `&&` | `and` |
| `||` | `or` |
| `!` | `not` |

Markdown 反引号 `` ` `` 只是文档中的代码标记，不是 C++ 位运算符。

## D11 `std::move`、转发引用与 `std::forward`

### 1. 命名变量是左值表达式

```cpp
void consume(std::string&& value) {
    // value 的声明类型是右值引用，
    // 但表达式 value 有名字，因此是左值表达式。
}
```

### 2. 转发引用

```cpp
template<class T>
void wrapper(T&& value) {
    consume(std::forward<T>(value));
}
```

只有当 `T` 是需要推导的、没有额外 `const` 限定的模板参数时，这种 `T&&` 才是转发引用。普通的 `std::string&&` 是右值引用，不是转发引用。

### 3. 引用折叠

| 组合 | 结果 |
|---|---|
| `T& &` | `T&` |
| `T& &&` | `T&` |
| `T&& &` | `T&` |
| `T&& &&` | `T&&` |

传入左值时，`T` 推导成左值引用；传入右值时，`T` 推导成非引用类型。`std::forward<T>` 根据这个推导结果恢复原始值类别。

### 4. `move` 与 `forward`

| 工具 | 行为 | 典型位置 |
|---|---|---|
| `std::move(x)` | 无条件把表达式转换成右值类别 | 明确转移资源 |
| `std::forward<T>(x)` | 根据 `T` 保留调用者原值类别 | 模板包装器、工厂函数 |

二者本身都只是转换，不保证真的移动；是否发生移动取决于随后选择的构造函数或重载。

### 5. 常见错误

- 忘记 `std::forward<T>` 的模板参数。
- 在非转发引用场景机械使用 `forward`。
- 对同一个可能被消耗的右值多次转发。
- 以为所有 `T&&` 都是转发引用。
- 以为 `std::move` 会立刻清空对象。

## D12 选择流程、记忆口诀与检查清单

### 1. 成员函数还是通用算法

```text
改变容器结构、容量或节点
    → 先想 container.member(...)

处理一个 [first,last) 范围
    → 先想 std::algorithm(first,last,...)

关联容器按 key 查询
    → 优先容器成员 find/count/lower_bound
```

语法提示：

```cpp
container.erase(pos);                     // 容器成员
std::find(container.begin(), container.end(), x); // 通用算法
```

### 2. 查询 map 的选择

```text
希望不存在时自动创建 value
    → mp[key]

确信应当存在，希望错误时抛异常
    → mp.at(key)

只查找且不改变容器
    → mp.find(key)

只判断存在
    → mp.count(key)
```

### 3. 删除选择

```text
已有迭代器，真正删除
    → it = container.erase(it)

vector 按值删除
    → erase(remove(...), end())

去掉相邻重复
    → unique + erase

整体排序去重
    → sort + unique + erase
```

### 4. 写循环时的检查清单

1. `end()` 是否只用于比较，没有被解引用？
2. 循环体是否插入或删除元素？
3. 操作是否可能触发 `vector` 扩容或哈希表 rehash？
4. 删除后是否使用了 `erase` 返回的新迭代器？
5. 算法是否要求有序范围或随机访问迭代器？
6. 是否错误使用 `operator[]` 做纯查询？
7. C++17/20 API 是否误写成 C++11？

### 5. 最终口诀

```text
容器管结构，算法管范围。
下标会插入，at 会抛异常，find 不修改。
remove 和 unique 只改逻辑范围，erase 才缩小容器。
vector 看扩容，unordered 看 rehash。
move 无条件转右值，forward 保留来时身份。
```
